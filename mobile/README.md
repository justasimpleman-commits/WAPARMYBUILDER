# Warhammer Army Builder — Mobile (Android via Capacitor)

This is the **cross-platform mobile build** of the army builder. It wraps the
**exact same `index.html` + data files** as the Electron desktop app inside a
[Capacitor](https://capacitorjs.com) native shell, so there is **one source of
truth** for the engine and army data (per the project's `CLAUDE.md`).

- The page feature-detects `window.armyAPI`. Inside the Android WebView that
  bridge is absent, so the app automatically uses its **IndexedDB** library and
  Blob download/upload fallback — save/load/export all work, no rewrite needed.
- `main.js` / `preload.js` (Electron-only) are **not** part of this build.

## Layout

```
mobile/
  capacitor.config.json   app id/name + webDir
  package.json            Capacitor deps + scripts
  sync-web.js             copies ../index.html + ../data/*.js into www/ (run before each build)
  build-android.command   one-click debug-APK build (macOS)
  www/
    index.html            copy of the desktop index.html (mobile-init.js auto-injected by sync)
    data/                 copy of ../data/*.js
    mobile-init.js        MOBILE-ONLY: safe-area/notch handling + Android Back-button
  android/                native Gradle project (generated by `cap add android`)
```

### Mobile-only behavior (`www/mobile-init.js`)

`mobile-init.js` lives only in the mobile build; `sync-web.js` injects a
`<script>` tag for it into the `www` copy of `index.html`, so the shared desktop
`index.html` is never modified. It adds:

- **Off-canvas drawers (phone layout)** — the Roster (your army list) stays as the
  full-width center. The **Catalog** slides in from the **left** (☰-style `＋ Units`
  button) and the **Army summary + Validation** slides in from the **right**
  (`Σ Summary` button); a scrim behind the drawer closes it on tap. The existing
  `#catalog` and validation nodes are *moved* (not cloned) into the drawer shells,
  so the app's `render()` keeps populating them by id — points, options, magic
  items and validation all work unchanged.
- **Hamburger (☰) menu** — Save, Library, Save to file, Open file, Export list and
  Clear army move into a drop-down sheet; the Army selector + Points limit stay in
  the top bar.
- **Safe-area / notch handling** — `viewport-fit=cover` plus `env(safe-area-inset-*)`
  padding so content clears notches and rounded corners.
- **Android hardware Back button** — closes the top (stacked) popup first, then the
  base modal, then any open drawer/menu, and only exits the app when nothing is
  open. Uses the `@capacitor/app` plugin; in a plain browser it's a no-op.

`app id`: `com.andras.warhammer.armybuilder` · `app name`: *Warhammer Army Builder*

## Build the debug APK

> ⚠️ The APK **cannot** be compiled in the Cowork sandbox — the Android SDK,
> Gradle distribution, and Google Maven are all blocked there, and only JDK 11 is
> available. Build on your Mac instead. Everything below is set up and ready.

**One-time prerequisites**
1. **Node.js** (already installed — you build the desktop app with it).
2. **JDK 17** and the **Android SDK**. The simplest way to get both:
   install **Android Studio**, open it once, and let it finish *SDK Components
   Setup*. (Android Studio bundles a JDK 17 and the SDK.)

**Then, every time you want an APK:**

```bash
cd "Army builder/mobile"
bash build-android.command      # or double-click it in Finder
```

The script installs deps, refreshes `www/` from the desktop source, runs
`cap sync`, and runs `./gradlew assembleDebug`. Result:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

Copy that file to your phone and tap it to install (enable *Install unknown
apps* for your file manager / browser).

### Run on a connected device instead
```bash
npm run build           # sync-web + cap sync
npx cap run android     # builds & launches on a plugged-in device/emulator
```

### Open in Android Studio (for an emulator, signing, or a release build)
```bash
npx cap open android
```

## Keeping mobile in sync with the desktop app

Whenever you edit `index.html` or any army data file in the desktop project, just
re-run the build script (or `node sync-web.js`) — it re-copies the latest files
into `www/` so the phone app never drifts from the desktop app.

## Release / Play Store build (later)

A debug APK is unsigned-for-distribution and fine for sideloading. For a Play
Store / shareable release you'll generate a signed `.aab`:
`cd android && ./gradlew bundleRelease` after configuring a signing key in
`android/app/build.gradle`. See Capacitor's *Deploying to Google Play* guide.

## iOS (the "cross-platform" other half)

The same Capacitor setup produces an iOS app: on a Mac with Xcode installed, run
`npx cap add ios` then `npx cap open ios`. (iOS builds require macOS + Xcode and
an Apple Developer account to run on a real device.)
